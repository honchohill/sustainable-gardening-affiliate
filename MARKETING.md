# Marketing Plan for Verdant — Sustainable Gardening Tools

## Positioning
Autonomous, price-comparing reviews of sustainable gardening tools across Amazon, Temu, Alibaba. One source of truth for eco-conscious buyers who want the best price without greenwashing.

## Core Channels — Autonomous by Design

1. **SEO Content Engine**
   - Agent publishes 3-5 reviews/week, each targeting long-tail keywords: "best compost bin 2026", "bamboo trowel vs metal", etc.
   - Each post includes comparison table across 3 marketplaces → captures comparison intent.
   - Internal linking between catalog and blog boosts topical authority.

2. **Short-form Video Resurfacing**
   - Agent auto-generates 30-60s scripts from reviews.
   - Post to TikTok/YouTube Shorts/Instagram Reels with link back to full review.
   - Hooks: "Amazon $79 vs Temu $52 — same bin?" → curiosity + price.

3. **Newsletter & RSS**
   - Weekly digest of new reviews + price drops.
   - RSS feed for power users, auto-generated from git commits.

4. **Community Seeding**
   - Auto-post summaries to Reddit r/gardening, r/ZeroWaste, r/BuyItForLife with disclosure.
   - Answer related questions on forums with link to in-depth review.

5. **Affiliate Stack**
   - Amazon Associates, Temu affiliate, Alibaba affiliate programs.
   - Multiple offers per product → maximize conversion.

## Growth Loops
- **Price Drop Alerts**: Agent monitors prices, emails subscribers when a product drops >10%.
- **User-Generated Validation**: Add comment section / GitHub Issues for community feedback, agent summarizes feedback into review updates.
- **Comparison Widgets**: Embeddable comparison table for other blogs to syndicate → backlinks.

## Metrics to Watch
- Organic traffic to review pages
- Click-through rate to affiliate links
- Price comparison page views
- Email signups from price alerts

## Launch Sequence
Week 1: Publish 10 seed reviews manually to establish topical coverage.
Week 2: Enable cron job for daily reviews.
Week 3: Start short-form video repurposing.
Week 4: Launch price-drop newsletter.

The site is built to be marketed by the same agent that builds it — content creation, distribution, and optimization all run autonomously once the pipeline is live.
